# 代码工作区与工作树

## I. 只读代码工作区、Diff 与引用

| 编号 / 功能                   | User story                                                                                                                        | 验收要点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-I01 边用终端边看代码       | 作为遥控开发任务的使用者，我希望在会话旁打开代码工作区，以便核对 agent 的工作而不离开终端。                                       | 宽屏并排且可调整分栏；窄屏切换终端与代码；导航开关、文件标签、刷新全部与独立窗口同在一行，根路径与导航状态提示在导航面板顶部；代码导航可折叠、调整宽度；窄于 640px 时文档栏操作收进“代码菜单”（显示完整路径），文档提示仍直接显示，Diff 内容区不少于 393×851 视口高度的 70%；切换保留同一 PTY，输出继续接收。                                                                                                                                                                                     |
| US-I02 确定阅读范围           | 作为使用者，我希望知道代码根目录对应哪份工作树，以便避免把另一个分支的代码当作当前任务。                                          | 根绑定会话启动目录所属 Git worktree，无 Git 时绑定启动目录；终端内 `cd` 不改变它；不越过符号链接、嵌套仓库等受保护边界读取。                                                                                                                                                                                                                                                                                                                                                                      |
| US-I03 浏览与搜索路径         | 作为使用者，我希望展开树状目录并按文件名或路径搜索，以便找到要核对的代码。                                                        | 目录在原位按需展开，可同时展开多个分支，保留父目录和同级项；缩进线、目录/文件图标、当前文件高亮和 Git 状态可识别；支持方向键/Home/End 导航、全部折叠和刷新，刷新、收起导航与切换修改页保留展开分支；搜索与按路径打开从紧凑工具栏进入，目录定位展开对应祖先路径；默认隐藏 Git 忽略的未跟踪项，可从菜单显式显示忽略项，切换后目录树与搜索使用相同范围；根目录和子目录均可分页，搜索或扫描受限时提示缩小范围；搜索中全部折叠回到真实根目录，不把搜索结果作为目录项；路径搜索不等同于全仓库正文搜索。 |
| US-I04 多标签只读阅读         | 作为使用者，我希望同时打开多个文件并查看高亮内容，以便在相关实现间切换。                                                          | 最多 20 个文件或 Diff 标签；支持激活与关闭，标明路径和来源；只读，不保存修改、不操作 Git 索引或配置；按文件名与扩展名识别常见语言并按需加载语法高亮，未识别时按纯文本显示。                                                                                                                                                                                                                                                                                                                       |
| US-I05 文件内定位             | 作为使用者，我希望在文件和 Diff 中查找文字、跳转行并调整阅读显示，以便迅速定位细节。                                              | 提供查找、上/下一个匹配、大小写/正则/全词选项和行号跳转；普通文件可切换行号，偏好跨设备同步；Diff 换行偏好同样同步；Diff 固定显示行号，保留自动换行和 Ctrl/⌘+Alt+G 跳转行快捷键。                                                                                                                                                                                                                                                                                                                 |
| US-I06 总览 Git 修改          | 作为使用者，我希望按未暂存、已暂存、未跟踪查看修改，并筛选路径，以便了解 agent 改了什么。                                         | 修改分组、来源和状态可识别；支持路径筛选、分页与大列表浏览；无 Git 时说明差异不可用，不阻止普通文件阅读。                                                                                                                                                                                                                                                                                                                                                                                         |
| US-I07 阅读 Diff              | 作为使用者，我希望 Diff 自动适配阅读宽度并能展开上下文，以便直接理解增删内容和周边代码。                                          | 显示新增/删除行数；宽度足够时并排、窄屏统一显示，固定保留行号，无需手动选择布局；按需展开上下文，区分新增、删除、重命名等变化；受限或计算失败时提示并提供重试或完整文件入口。                                                                                                                                                                                                                                                                                                                     |
| US-I08 切换完整文件和比较来源 | 作为使用者，我希望从文件查看 Diff，也能打开 Diff 两侧完整文件，以便在变更与完整上下文间切换。                                     | 根据修改组比较工作树、索引与 HEAD；通过一个“完整文件”菜单打开同一快照修改前或修改后的文件，不提供不存在的版本；文件与 Diff 切换只展示下一步操作；窄于 640px 时这些操作在“代码菜单”中；无差异或来源已变更时保留阅读并提示，不悄悄换成不同版本。                                                                                                                                                                                                                                                    |
| US-I09 插入文件和行引用       | 作为使用者，我希望把整个文件、某行或连续行范围发送给终端或草稿，以便准确告诉 agent 关注哪里。                                     | 桌面行号选择、Shift 连选，触摸点行后点“＋”；文字 Diff 根据选中行自动确定引用版本，无需选择旧侧/新侧；默认引用修改后版本，已删除文件引用修改前版本；文件与 Diff 都在选行后才显示“引用整个文件”；操作栏单行，宽屏左侧显示引用版本和选择方式提示，窄屏省略提示；生成绝对路径及可选行范围，不回车，路径正确转义；索引/HEAD 引用注明版本，不能把跨两侧选择伪装成同一来源。                                                                                                                             |
| US-I10 发现变化后手动刷新     | 作为使用者，我希望阅读时收到外部更新提示，再决定何时刷新，以便不被 agent 的写入打断。                                             | 代码可见且页面在前台时约每 5 秒检查，也在恢复可见或连接时检查；文件、目录、修改列表提示更新、删除或未知状态；保留旧内容，显式刷新才替换；状态异常时阻止发送陈旧引用。                                                                                                                                                                                                                                                                                                                             |
| US-I11 识别不可阅读内容       | 作为使用者，我希望二进制、超大文件或不支持的路径给出清楚说明，以便知道为何没有正常代码视图。                                      | 单个文本文件最多 2 MiB / 20000 行，图片另按 US-I15 的上限预览，单目录最多检查 10000 项；非图片二进制、空或无法识别的图片、特殊文件、子模块等按支持范围展示元信息或边界；受限结果不冒充完整结果。                                                                                                                                                                                                                                                                                                  |
| US-I12 隔离快照与会话         | 作为使用者，我希望代码快照始终属于当前会话，并在过期时明确提示，以便不发送错误版本的引用。                                        | 上下文与快照按会话校验，不能跨会话复用；快照过期时保留旧画面并提示刷新；不把过期快照默认为当前文件。                                                                                                                                                                                                                                                                                                                                                                                              |
| US-I13 独立代码窗口           | 作为桌面使用者，我希望把代码工作区弹到独立窗口，以便同时给终端和代码留出更大阅读空间。                                            | 支持时使用置顶画中画，否则回退普通弹出窗口；保留标签、引用与变化检测；主页面显示占位，可收回；关闭独立窗口恢复原位，离开或刷新主页面会关闭它；不支持画中画且无精细指针，或在带触摸屏设备的主屏幕 Web App 中时隐藏入口，窄于 640px 时也不显示；弹窗被拦截时提示。                                                                                                                                                                                                                                  |
| US-I14 按路径打开             | 作为在终端里 `cd` 的使用者，我希望输入相对当前目录的路径直接打开文件，以便不必从代码根逐层查找。                                  | 相对路径以本机 Shell 报告目录为基点，无报告时用启动目录，也接受绝对路径；服务端解析符号链接后必须位于代码根内，目录跳转到文件树；远端报告、根外路径、`.git` 内部、不存在路径和特殊文件给出明确错误；读取仍走既有边界检查。                                                                                                                                                                                                                                                                        |
| US-I15 预览与下载图片         | 作为远程核对 agent 产物的使用者，我希望在代码工作区直接查看图片并下载到当前设备，以便确认截图、图表等生成结果。                   | PNG、JPEG、GIF、WebP、AVIF、BMP、ICO 按扩展名加文件头识别并预览，可适应窗口、1:1、缩放、拖动和双指缩放，显示格式、像素尺寸与大小；图片工具栏单行，窄屏触摸设备只保留适应窗口与 1:1，缩放靠双指；SVG 默认预览、可切源码，脚本与外部资源不生效；20 MiB 以上只显示元信息，100 MiB 内可下载且字节一致、保留原名；图片 Diff 显示变更与大小并可切换修改前/修改后版本；文件变化、快照过期、过大与未认证给出明确错误，token 不进 URL。                                                                    |
| US-I16 预览 Markdown          | 作为阅读 README、设计文档或说明的使用者，我希望在代码工作区直接查看 Markdown 的排版结果，以便确认标题、列表、代码块和链接的呈现。 | 打开 `.md`、`.markdown`、`.mdown` 或 `.mkd` 文本文件时，文档栏（窄屏为“代码菜单”）提供“预览”按钮切换到渲染视图，并可“返回源码”；渲染标题、列表、代码块、表格和链接；原始 HTML 经清洗，不执行脚本、不加载图片或外部资源；相对链接不导航，HTTP(S)/mailto 链接在新标签页打开；切换文件或 Diff 后回到源码模式，预览状态不写入设置。                                                                                                                                                                   |

## J. 仓库登记与 worktree 管理

| 编号 / 功能                   | User story                                                                                                | 验收要点                                                                                                                                                                                                                |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-J01 登记已有仓库           | 作为使用者，我希望通过主仓库、worktree 或子目录登记已有 Git 仓库，以便集中管理项目的工作树。              | 同一仓库只登记一次；只登记可信的现有目录，不 init 或 clone；登记保存在服务端状态目录，重启后仍在。                                                                                                                      |
| US-J02 查看工作树状态         | 作为使用者，我希望看到分支、路径和工作树可用性，以便选择正确的代码副本。                                  | 显示主工作区、linked、bare、detached、锁定及原因、待清理、已跟踪修改和未跟踪状态；无法判断时显示未知或错误，bare 不可启动会话。                                                                                         |
| US-J03 选择主页工作树         | 作为有大量工作树的使用者，我希望只把关注的工作树放到主页，以便降低总览噪声。                              | 默认主工作区可见，新建 worktree 自动添加；可按分支/路径搜索、多选添加或从主页移除；有会话的工作树始终显示，未添加者有标记；选择保存到服务端并跨设备同步，409 按 ID 重放；只读展示过滤不自动保存；移出主页不删除工作树。 |
| US-J04 为新任务创建分支工作树 | 作为使用者，我希望从已有本地基线创建新分支与 worktree，以便隔离新任务的文件变更。                         | 基线可为本地分支、已有远程跟踪引用或提交 OID；提供避开已有分支和目录的建议名及“换一个”；默认放在仓库旁的 worktrees 目录，目录名取分支末段，可修改完整路径，不覆盖已有目录。                                             |
| US-J05 检出现有分支           | 作为使用者，我希望搜索并选择未被占用的本地分支创建 worktree，以便继续已有工作。                           | 支持按名称搜索和键盘选择；已被其他工作树占用的分支禁选；不自动 fetch 远端分支。                                                                                                                                         |
| US-J06 单独创建与保留工作树   | 作为使用者，我希望工作树独立于会话存在，以便先准备环境或在任务结束后继续使用。                            | 可只创建工作树；仅检出版本控制内容，不复制 `.env` 或安装依赖；启动失败、关闭会话或服务重启不会自动删目录和分支。                                                                                                        |
| US-J07 同一工作树多个会话     | 作为使用者，我希望在同一 worktree 启动多个终端，以便同时运行 agent、测试或开发服务器。                    | 多个 PTY 独立运行但共享同一份工作树文件；启动目录或其子目录可关联工作树；关联基于启动位置，不实时跟踪终端里的 `cd`。                                                                                                    |
| US-J08 安全删除预览           | 作为使用者，我希望删除 worktree 前看到受保护文件和关联会话，以便避免丢失工作。                            | 安全删除拒绝未提交、未跟踪、忽略文件或活动会话；主工作区、bare、locked、含子模块等目标受保护；预览显示阻止原因和关联会话；有效确认限时且目标或会话变化后需重新预览。                                                    |
| US-J09 明确强制删除           | 作为确实要丢弃任务的使用者，我希望在核对完整路径和相关会话后强制删除，以便清理不再需要的 worktree。       | 仅允许可强制删除的目标；须输入完整路径并勾选关闭列出会话及删除全部内容的确认；可能丢弃未提交及忽略文件；保留分支与已退出记录；不能保证处理外部进程或终端 `cd` 后的归属。                                                |
| US-J10 移除仓库登记           | 作为使用者，我希望把不再关注的仓库从列表移除，以便整理项目清单。                                          | 确认后仅移除持久登记，不删目录或分支，不关闭会话；原会话仍可在直接会话中访问。                                                                                                                                          |
| US-J11 局部失败时继续使用     | 作为使用者，我希望一个仓库损坏、路径消失或 Git 不可用时仍能使用其他终端，以便局部环境问题不阻断全部工作。 | 单仓库失败保留错误和原会话入口；Git 缺失或仓库存储不可用时禁用相关管理能力，直接目录终端仍可用；损坏清单不被静默覆盖。                                                                                                  |
