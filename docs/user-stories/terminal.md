# 终端、输入与移动端

## D. 终端操作、续接、多设备与生命周期

| 编号 / 功能                   | User story                                                                                                              | 验收要点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| US-D01 使用交互终端           | 作为使用者，我希望在浏览器里直接键入、查看彩色输出并操作全屏 TUI，以便像使用本地终端一样工作。                          | 原始 PTY 字节送入 xterm；支持控制序列与终端尺寸适配；终端输出不被当作普通聊天文本重排。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| US-D02 离开页面后继续运行     | 作为远程使用者，我希望关闭标签页、手机锁屏或切换网络后进程仍继续运行，以便长任务不依赖浏览器在线。                      | 浏览器取消连接只解除附着；服务存活期间会话继续运行，可从列表或原链接再次进入。服务端内部消息非法或无法编码时，以 1011 关闭当前连接，不记录载荷、不终止持久会话。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| US-D03 自动重连与缺失输出续接 | 作为使用者，我希望断线或回到前台后自动恢复终端，以便继续工作且不漏掉断线期间保留的输出。                                | 断线后退避重连；代际和续接点有效时只追加缺失字节，即使更早历史被覆盖也保留现有终端与查找状态；否则重置终端，未截断时回放缓冲，已截断时仅初始化模式、不回放旧文本，并请求程序重绘，再无缝接入实时流；完整重置清除旧查找标记并提示按 Enter 重查；慢客户端断开而不阻塞 PTY；普通 pageshow 不替换连接，前台与 bfcache 恢复会续接，释放后的迟到事件不再更新页面；连接正常时顶栏只显示有名称和提示的状态点。                                                                                                                                                                                                                                                                                                                                                                                           |
| US-D04 查看保留历史           | 作为使用者，我希望重开会话后查看最近输出，并知道更早的记录是否已被覆盖，以便判断历史是否完整。                          | 默认每会话保留 2 MiB 原始字节，可配置；截断后的完整恢复不把任意后缀当作完整屏幕，而是清空不可恢复的历史并请求程序重绘，不显示历史丢弃或重绘请求提示；查找范围与复制缓冲中的截断标记仍保留；通过短暂改变实际 PTY 列数再恢复请求重绘，不注入按键、不接管控制，并发控制端 resize 优先；程序不响应时不保证恢复成功，已退出程序不能重绘；诊断/复制原始缓冲仍可用，有界缓冲不是永久日志或完整 VT 状态。                                                                                                                                                                                                                                                                                                                                                                                                |
| US-D05 多设备观察             | 作为在电脑与手机间切换的使用者，我希望同时打开同一会话并观察输出，以便跨设备接续任务。                                  | 各端连接同一个 PTY；后连接设备默认观察，按控制端网格显示并允许平移；观察端窗口或键盘变化不改变共享 PTY 尺寸。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| US-D06 接管输入与尺寸控制     | 作为观察端使用者，我希望主动接管终端，以便在当前设备上输入并采用适合它的终端尺寸。                                      | 显示控制设备；输入、发送草稿、点键盘按钮或显式接管可转移控制权；仅控制端可改变尺寸；控制端断开后等待下一次接管，终端设备查询避免重复应答。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| US-D07 阅读与恢复画面         | 作为使用者，我希望滚动历史后能回到最新输出，并能清屏或重新同步，以便处理长输出和异常画面。                              | 提供滚动到最新位置（窄于 640px 时在终端菜单中）、清屏和重新同步；重新同步与重开页面使用同一安全快照恢复路径，历史截断时清空不可恢复内容并请求重绘；窄屏终端离开底部（含观察端平移离开最新行）时右下角显示带文字的“回到最新”，点击回到最新输出且不取得焦点、不开合键盘，回到底部自动隐藏；这些操作不创建新会话，也不结束进程；复制全部缓冲独立于当前可见区域。                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| US-D08 全屏与字体             | 作为使用者，我希望进入全屏并调整字体，以便在不同屏幕上留出更多终端空间。                                                | 浏览器支持时可进入和退出原生全屏（窄于 640px 时在终端菜单中）；不支持时浏览器标签页提示添加到主屏幕，主屏幕 Web App 中不显示全屏入口；字体可在 8–20px 间调整，保存在服务端、跨设备同步并用于终端布局。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| US-D09 查看退出结果           | 作为使用者，我希望程序结束后仍能看到退出码和最后输出，以便确认成功或排查失败。                                          | 最终输出排空后发布退出；退出码与原始缓冲保留至手动移除；已退出会话不再接受终端输入；退出后的前台恢复与手动重新同步仍使用安全 WebSocket 快照，缓冲已截断时清空不能重建的历史，不显示历史丢弃或无法重绘提示，不把原始后缀写入终端。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| US-D10 关闭和移除会话         | 作为使用者，我希望明确终止不再需要的任务，再清除会话记录，以便管理进程与列表。                                          | 关闭前确认，先 SIGHUP、超时后 SIGKILL，并按平台能力清理后代；关闭后保留输出；移除前另行确认且只允许移除已退出会话；不删除工作树；macOS 自守护进程边界见 [部署说明](../deployment.md#平台差异)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| US-D11 查找终端输出           | 作为阅读长输出的使用者，我希望在当前终端缓冲中查找文字并复制匹配，以便定位错误而不向程序发送输入。                      | 终端菜单“查找”、Ctrl+Shift+F 或 macOS Cmd+F 打开查找栏，普通 Ctrl+F 不拦截；从当前视口开始，支持大小写、全词、正则、上/下一个匹配及 Enter/Shift+Enter，Esc 关闭；显示当前序号、无匹配与无效正则，达到 1000 个时明确只统计前 1000 个；范围限当前 xterm 缓冲（默认最多回看 10000 行），全屏程序只查当前屏幕，服务端历史截断另行提示，不检索已覆盖输出或服务端原始字节；输入法组合期间不查找、不误触 Enter/Esc；查找不写入 PTY、不接管控制、不改变共享尺寸或草稿；可复制选中，权限不足沿用手动复制；关闭、清屏及缓冲切换清除标记，完整回放期间暂停且完成后需重查，增量续接保留查找；桌面关闭后恢复终端/草稿焦点，触屏不强制弹出终端键盘，窄屏控件可换行。                                                                                                                                           |
| US-D12 显示终端图片           | 作为运行会输出图片的终端程序的使用者，我希望在浏览器终端里直接看到 Kitty 图形协议的图片，以便预览截图、图表和图像输出。 | 识别 APC `ESC_G…ESC\`；支持直接传输的 PNG、RGB、RGBA、分块传输、图片与放置 ID、图像编号、源矩形裁剪、按单元格缩放与偏移、`C=1` 光标策略及各类删除；查询由控制端浏览器在后续文本前答复，回放历史不回发旧响应；普通/备用屏幕的图片隔离；`CSI 2J` 清屏删除对应放置，局部文本擦除不删除图片；图片随输出滚动并可随历史视口重新显示，历史截断释放对应放置；omp 顶部裁剪及只重绘文字时保留正确图片，不依赖会被文本擦除删除的 xterm marker；解码、图像数量、放置及画布资源有界，超限请求被拒绝，后续尺寸变化超限时释放放置；图片只绘制在浏览器终端，不进入会话列表文本预览；omp 18.12.6 使用 `PI_FORCE_IMAGE_PROTOCOL=kitty`（首次预置配置已设置），不承诺所有程序自动探测；不支持文件/共享内存介质、动画、Unicode 占位符和相对父放置，不支持的相对放置返回 `ENOTSUP`；负 z-index 图片仍显示在文字上方。 |

## E. 剪贴板与文件上传

| 编号 / 功能               | User story                                                                                               | 验收要点                                                                                                                                               |
| ------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| US-E01 复制选中与全部缓冲 | 作为使用者，我希望复制选中文字或当前服务端保留的全部输出，以便分享结果和排查问题。                       | 桌面提供 Ctrl+Shift+C；触摸选择提供复制按钮；菜单可复制全部缓冲；缓冲被截断时注明更早输出已覆盖。                                                      |
| US-E02 粘贴文本与降级操作 | 作为使用者，我希望粘贴多行文本，并在剪贴板权限不可用时仍能手动操作，以便在 HTTP 或受限浏览器中输入。     | 提供 Ctrl+Shift+V 和粘贴入口；遵循目标程序的 bracketed paste 模式；剪贴板读写被拒绝时提供手动文本框；未启用 bracketed paste 的程序可能把换行当作提交。 |
| US-E03 接收程序复制请求   | 作为使用者，我希望终端程序的 OSC 52 复制请求能进入浏览器剪贴板，以便沿用 CLI 的复制操作。                | 在线请求可复制，权限不足时手动复制；历史回放不重复执行复制请求。                                                                                       |
| US-E04 多种方式上传文件   | 作为使用者，我希望选择、拖放或粘贴文件和图片，以便向服务器上的 agent 提供素材。                          | 文件选择支持多个文件依次上传；拖放与剪贴板文件进入同一上传流程；文件粘贴优先于伴随文本，普通文本仍按文本输入。                                         |
| US-E05 插入上传路径       | 作为使用者，我希望上传完成后自动获得可用的服务器路径，以便把文件交给终端程序。                           | 成功后插入带 shell 引号的绝对路径且不回车；草稿模式下插入草稿；保存到独立临时目录而非工作区；已成功文件不随会话关闭自动删除。                          |
| US-E06 查看进度与取消     | 作为使用者，我希望看到文件名、批次进度并随时取消，以便控制大文件上传。                                   | 显示当前文件、序号、百分比和等待终端恢复状态；单文件上限 100 MiB、上传期限 5 分钟；取消或失败清理未完成文件，不伪造成功路径。                          |
| US-E07 恢复期间的上传交接 | 作为使用者，我希望重连、切换草稿或上传部分失败时仍能准确拿到已上传文件的路径，以便避免丢失素材或误输入。 | 路径等待输入目标就绪后插入；取消后不在重连时补插；切换为草稿时可交给草稿；已上传但未插入时提示真实路径，保留已成功插入的结果；退出会话拒绝新上传。     |

## F. 草稿编写、保存与发送确认

| 编号 / 功能                 | User story                                                                                                                                  | 验收要点                                                                                                                                                                                                                                                                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-F01 多行编写             | 作为向 agent 描述任务的使用者，我希望先在草稿框中整理多行文字，以便写完再统一提交。                                                         | 显式开启草稿；可调整面板高度；输入、换行、粘贴和编辑留在当前草稿，Enter 不直接提交；当前草稿与暂存是两个独立编辑目标，暂存只在显式取用时进入当前草稿；输入法组合期间不发送。                                                                                                                                                                         |
| US-F02 组合输入素材         | 作为使用者，我希望键盘文字、软键字符、代码引用、上传路径和快捷指令汇入同一草稿，以便组织完整上下文。                                        | 按草稿光标或选择范围插入；开启草稿时不直接写入 PTY；异步输入只进入当前草稿，不串到其他会话或暂存条目；终端控制键被拦截并提示先退出草稿。                                                                                                                                                                                                             |
| US-F03 隐藏、恢复与清空     | 作为使用者，我希望暂时隐藏草稿而保留内容，也能明确清空，以便在直接操控和编写之间切换。                                                      | 关闭草稿仅隐藏当前草稿和暂存面板，不发送或清空；隐藏期间收到插入或暂存更新时有提示；草稿栏以图标和数量徽标打开暂存，清空图标提供名称提示；清空当前草稿与清空暂存分别确认，删除对应本机保存，不删除已上传文件。                                                                                                                                       |
| US-F04 明确发送与确认       | 作为使用者，我希望点击发送后知道正文是否写入终端，以便避免把点击成功误当作任务已执行。                                                      | 正文与一次 Enter 作为同一提交；显示发送、收到、写入等状态；确认写入后清空并收起；确认前锁定正文；“已写入终端”不代表 agent 已接受或执行成功。                                                                                                                                                                                                         |
| US-F05 处理断线与不确定结果 | 作为使用者，我希望发送中断后查询原提交结果，以便避免重复向 agent 下达任务。                                                                 | 断线显示结果未知；重连后查询原 ID；允许按原提交重发并在当前会话有效记录范围内去重，或转为草稿；失败、部分写入、无记录分别提示；不自动把未知正文作为新提交重发。                                                                                                                                                                                      |
| US-F06 按会话保存和恢复     | 作为使用者，我希望刷新、关闭页面或重新认证后恢复未完成草稿，以便继续编辑而不丢失任务描述。                                                  | 当前浏览器按会话保存当前草稿、未确认提交和暂存；恢复时显示目标会话并查询已有提交；暂存来自较早会话实例时提示但不自动发送；恢复不自动发送；会话实例变化不能沿用旧实例的发送确认。                                                                                                                                                                     |
| US-F07 管理本机草稿         | 作为重视本机数据保留的使用者，我希望关闭草稿保存、查看数量或清除保存内容，以便控制浏览器中的任务文本。                                      | 设置显示 N 个会话的草稿与 M 条暂存；关闭保存立即删除已存草稿和暂存，之后仅保留页面内存；清除全部需确认；7 天未修改或会话不存在时清理；超出本机保存限制时提示仅保留当前页面。                                                                                                                                                                         |
| US-F08 离线和退出后继续整理 | 作为使用者，我希望终端不可发送时仍能编辑或复制草稿，以便先完成文字整理。                                                                    | 断线、回放未完成或会话退出时禁用发送并给出原因；草稿仍可编辑，暂存仍可查看、编辑、排序和取用；取用不发送；恢复连接后由用户手动决定发送；会话已移除时清理其草稿和暂存。                                                                                                                                                                               |
| US-F09 多条暂存             | 作为需要连续安排多个任务的使用者，我希望为同一会话保留多条暂存文本并分别编辑、排序和取用，以便 agent 工作时先记下后续任务而不覆盖当前草稿。 | 当前草稿与暂存为不同编辑目标；列表独立滚动，新建区保持可达；可直接编辑和通过带名称提示的图标取用，排序、删除位于条目菜单，清空使用图标并二次确认；显示条数、字符数及满额原因；取用前处理与当前正文的追加或替换冲突，替换时先把原正文保留为暂存；未确认提交期间禁止转存和取用；取用不自动发送或聚焦终端；存储禁用、损坏或超额时保留页面内编辑并提示。 |

| US-G01 保存常用文字           | 作为使用者，我希望保存常用命令或多行提示词，以便减少重复输入。                                 | 设置中可新增与编辑名称、正文和是否追加回车；正文统一换行并移除末尾换行；最多 50 条；首次未保存列表时提供 `/resume` 与 `/new`。                                        |
| US-G02 一键发送或插入         | 作为使用者，我希望从终端或底部工具栏打开快捷指令，以便把常用内容送往当前输入目标。             | 菜单显示名称、正文摘要与回车标记；直接模式按配置发送正文或正文加回车；草稿模式只插入正文，不因回车选项提交草稿；发送时清除软键修饰状态。                              |
| US-G03 排序与删除             | 作为使用者，我希望调整指令顺序并删除不再使用的内容，以便把常用项放在前面。                     | 支持上移、下移和确认删除；顺序保存；主动清空列表后保持空列表，不重新生成默认项。                                                                                      |
| US-G04 服务端保存与跨设备更新 | 作为使用者，我希望指令跨设备持续可用，并能实时看到其他设备的修改，以便保持自己的指令列表一致。 | 列表通过 settings.json 保存并由 WebSocket 同步；null 使用预置项，空数组保持清空；存储损坏保留原文件并禁写；冲突按 ID 重试一次，编辑失败保留正文；旧浏览器偏好不上传。 |
| US-G05 不可发送时保留意图     | 作为使用者，我希望终端未就绪时明确禁止直接发送，以便避免指令静默丢失。                         | 断线、回放或退出时提示不可发送；草稿仍可接收指令；带回车提交的未知、失败、部分写入等结果有提示，重连后查询结果。                                                      |

## H. 手机、平板与触摸操作

| 编号 / 功能               | User story                                                                                                     | 验收要点                                                                                                                                                                                                                                                                                                                          |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-H01 使用软键栏         | 作为手机或平板使用者，我希望直接点击终端特殊按键，以便不依赖实体键盘操控 CLI。                                 | 触摸设备默认显示可横向滚动的软键栏；包含键盘、粘贴、快捷指令、`/`、`@`、Esc、Tab、Ctrl、Alt、方向、Home/End、翻页和常用 Ctrl 组合键；Ctrl/Alt 为一次性修饰。                                                                                                                                                                      |
| US-H02 主动开合键盘       | 作为触摸设备使用者，我希望自己决定何时打开虚拟键盘，以便阅读和点选时保留屏幕空间。                             | 只有点击键盘按钮才主动唤起或收起；已唤起时点击方向键、Esc、Tab 等发送软键保持焦点、不收起键盘；打开快捷指令菜单或粘贴对话框时焦点转入弹层；进入终端、轻点或笔点终端、开启草稿、关闭弹窗和上传完成均不自动唤起；系统返回键收起键盘后，轻点、滑动或笔点终端不重新唤起，键盘按钮仍可重新打开；带笔或实体键盘的触摸平板也遵循此规则。 |
| US-H03 滚动历史与 TUI     | 作为触摸设备使用者，我希望用单指滑动查看终端内容，以便在没有鼠标滚轮时浏览长输出。                             | 普通终端滑动滚动历史；启用鼠标交互的全屏 TUI 中转换为相应滚轮事件；不将滚动误作键入。                                                                                                                                                                                                                                             |
| US-H04 捏合调字体         | 作为触摸设备使用者，我希望双指捏合改变文字大小，以便临时放大难读的终端内容。                                   | 调整范围为 8–20px，与字体设置一致；本地即时预览，连续调整停下 250ms 后合并保存最终值，离开页面时提交待保存值；手势结束后恢复正常滚动与选择。                                                                                                                                                                                      |
| US-H05 长按选择复制       | 作为手机使用者，我希望长按选词并拖动扩选，以便复制命令结果或错误信息。                                         | 约 0.5 秒长按选词；支持宽字符与跨行扩选；显示复制选中入口，权限不足时提供可手动复制的选中文字；选择不向终端输入。                                                                                                                                                                                                                 |
| US-H06 键盘视口与独立运行 | 作为手机使用者，我希望键盘开合和横竖屏变化时仍能使用终端，以便在小屏幕持续工作。                               | 页面按可见视口适配；终端输入关闭自动大写、纠错和拼写检查；支持浏览器添加到主屏幕后的独立显示；依赖平台的键盘、选择菜单与锁屏行为仍需真机验证。                                                                                                                                                                                    |
| US-H07 桌面启用底部工具栏 | 作为使用鼠标或实体键盘的使用者，我希望也能显示软键工具栏，以便点击常用操作。                                   | 终端菜单可强制显示或关闭底部工具栏；快捷指令入口随布局保持可达。                                                                                                                                                                                                                                                                  |
| US-H08 窄屏紧凑顶栏       | 作为在手机或主屏幕 Web App 中查看 agent 的使用者，我希望顶栏只保留常用操作，以便看清会话名称并把高度留给终端。 | 窄于 640px 时顶栏单行，只常驻返回、标题、状态点、快捷指令入口（按既有规则）、草稿、终端/代码切换和终端菜单；全屏、上传文件、滚动到最新位置在终端菜单中，名称与禁用条件不变；320px 下无横向溢出，393px 下完整显示较短标题；宽屏按钮集合不变；返回按钮始终可用。                                                                    |
