## 后续维护

每次新增或修改功能时，在对应分组补充或更新故事、验收要点和代码依据，并更新覆盖索引。代码、使用指南与故事不一致时，先核对实际行为，再明确这是实现缺陷、文档错误还是待实现需求；不要把规划中的故事直接标作现有能力。
