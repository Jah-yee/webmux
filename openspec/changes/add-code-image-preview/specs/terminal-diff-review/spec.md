## MODIFIED Requirements

### Requirement: 完整文件只读且可辨识

系统 SHALL 显示所选文本文件的完整可读取内容、真实行号、语言高亮、读取时间和来源标签；不支持的语言降级为纯文本。阅读 SHALL 不编辑、保存或执行代码。已识别的图片 SHALL 按图片预览能力展示，不受文本 2 MiB / 20000 行上限约束。其余二进制、不可支持编码和超限文件 SHALL 给出文件信息与原因，不将部分内容标为完整。

#### Scenario: 新文件与纯净文件

- **WHEN** 用户打开未跟踪文本或没有任何修改的文本文件
- **THEN** 两者均可从首行阅读至末行，未跟踪状态独立标注，代码阅读不创建或修改 Git 索引

#### Scenario: 文件不可完整展示

- **WHEN** 文件是非图片二进制、编码无法可靠解码或超过读取上限
- **THEN** 展示路径、类型及受限原因，允许可表示路径的文件级引用，不伪造行号或提供未显示的行引用

#### Scenario: 图片文件

- **WHEN** 用户打开根内已识别的 PNG 图片
- **THEN** 面板显示图片预览与元信息而不是“二进制内容”，仍允许文件级引用，不提供行号或行引用

### Requirement: 代码读取沿用会话访问边界

目录、搜索、文件、差异、快照、原始字节和检测接口 SHALL 沿用认证与 Origin 策略，并验证会话、绑定根、路径及来源。完整文件读取 SHALL 允许无修改文件，但拒绝越界、Git 内部数据和跨会话快照引用。文本内容 SHALL 以代码文本渲染，不执行 HTML、脚本或终端控制序列，也不写入日志；已识别图片（含 SVG）SHALL 仅在禁止脚本与外部资源的图片上下文中渲染。

#### Scenario: 未修改文件与非法目标

- **WHEN** 用户读取根内正常未修改文件，或客户端尝试 ../、绝对路径、.git、另一会话的 snapshotId
- **THEN** 前者成功，其余被拒绝且不返回目标内容，不以“仅修改文件白名单”阻挡合法浏览

#### Scenario: 文件包含主动内容

- **WHEN** 源文件包含 HTML、脚本或 ANSI 控制字符
- **THEN** 阅读器作为源码或可辨识转义显示，不执行内容、不改变终端状态

#### Scenario: SVG 包含脚本

- **WHEN** 用户预览含 `<script>` 与外部资源引用的 SVG
- **THEN** 只显示静态图形，脚本不执行、外部资源不加载，源码视图仍按文本显示
