# Spec Delta

## Purpose

让用户从当前会话代码区的完整文件、Diff 修改行或展开的普通上下文选择文件、单行与连续范围，生成准确路径、行号及版本来源的位置引用，并插入当前终端交给 agent。选择跟随文档和内容版本，支持多文件阅读与手机操作，由用户自行补充要求并提交。

## ADDED Requirements

### Requirement: 完整文件与普通上下文均可选择

系统 SHALL 在完整文件、Diff 和已展开的普通上下文中支持文件级、单行及同侧连续范围选择，不以内容有修改为前提。桌面 SHALL 支持行号点击与 Shift 扩选，触屏 SHALL 支持起点/终点操作；选区可见、可清除。跨文件、跨侧或尚未展开的间隔 SHALL NOT 静默拼成连续选区。

#### Scenario: 发送没有修改的文件位置

- **WHEN** 用户从文件树打开没有 diff 的文件，选中第 12–18 行
- **THEN** 可以预览并发送该位置，不要求修改文件、切到 Diff 或创建新会话

#### Scenario: 发送展开的普通行

- **WHEN** 用户展开 diff 块之间的未修改上下文并选择其中连续行
- **THEN** 与修改行使用相同的发送操作，行号来自展开内容的真实比较侧

#### Scenario: 只有文件信息

- **WHEN** 文件为二进制、超限、冲突差异或纯元数据变化
- **THEN** 可以选择可表示的文件路径，不能选择不存在或未展示的行；若当前工作区文本本身可读，仍可打开完整文件另行选行

### Requirement: 引用准确表达路径和内容来源

系统 SHALL 使用浏览根下所选文档/比较侧的绝对路径，生成文件、path:line 或 path:start-end 引用。当前工作区行使用当前文件行号；索引、HEAD 和删除旧侧 SHALL 显示明确来源，不冒充当前工作区位置。特殊路径 SHALL 可逆转义，CR/LF/ESC 等控制字符不得原样进入终端。

#### Scenario: 子目录启动后引用根内普通文件

- **WHEN** agent 从 packages/app 启动，用户选择同一工作树 src/main.go 第 12–18 行
- **THEN** 引用使用正确工作树中的绝对文件路径和行号，既不相对 agent cwd 错算，也不指向主工作区同名文件

#### Scenario: 完整索引版本与旧侧行

- **WHEN** 用户从 diff 打开完整索引版本，或选择已暂存删除的 HEAD 旧侧行
- **THEN** 引用分别标明索引版本或 HEAD 旧版本，使用该版本的路径/行号，而非工作区当前行号

#### Scenario: 特殊文件路径

- **WHEN** 路径含空格、引号、冒号、换行、反斜杠或控制字符
- **THEN** 预览与插入使用相同的无原始控制字符转义文本，无法无损表示的路径禁用发送并给出原因

### Requirement: 选区与多文件标签独立绑定

选区 SHALL 绑定会话、文档、来源和内容版本。切换标签可保留各自有效选择，但发送动作 SHALL 仅作用于当前激活文档，并显示其文件名/范围/来源预览；切换到另一会话 SHALL 清空原会话交互状态，不能向其他 PTY 注入位置。

#### Scenario: 切换到已选中另一范围的文件

- **WHEN** A 中选中 12–18 行，B 中选中 30 行，用户在两标签间切换
- **THEN** 各自恢复自己的选择，发送预览总与活动标签一致，不把 A 的路径配上 B 的行号

#### Scenario: 会话切换时请求仍在运行

- **WHEN** 用户从会话 A 导航到 B，A 的代码读取随后返回
- **THEN** A 的响应、选择和引用不进入 B，也不会写入 B 的终端

### Requirement: 发送沿用当前终端粘贴且不自动提交

系统 SHALL 提供明确的“发送位置到终端”动作，将预览位置插入当前会话输入光标处，保留已有输入并遵循应用的粘贴模式。系统 SHALL 不自动追加回车、不清空输入、不发送控制键、不自动调用 agent API；普通 Shell 和任意 agent 预设使用相同语义。

#### Scenario: 已有输入时插入普通代码位置

- **WHEN** 当前 agent 输入区已有一段要求，用户点击发送位置
- **THEN** 引用经终端粘贴通道插入，原内容保留，用户自行补充文字和按回车

#### Scenario: 当前终端是 Shell

- **WHEN** 用户在 Shell 会话中点击发送
- **THEN** 仅插入位置文本，不包装或执行 shell 命令，不声称 agent 已执行任务

### Requirement: 发送失败不丢选择也不自动重发

终端未初始化、断开、恢复中、退出或不存在时，发送 SHALL 禁用或明确拒绝；失败保留当前文档与选择，重连不自动补发。成功反馈 SHALL 仅表示已提交当前可用终端连接，不声称 agent 已确认接收、阅读或处理。

#### Scenario: 点击瞬间断线

- **WHEN** 用户点击发送时连接不可用
- **THEN** 显示未发送并保留选择，连接恢复后需要用户重新点击

#### Scenario: 本地提交后网络中断

- **WHEN** WebSocket 接受本地发送后连接断开
- **THEN** 不自动重试造成重复输入，也不将本地发送结果描述为远端处理确认

### Requirement: 手机发送返回原终端

窄屏下位置发送成功 SHALL 从“代码”切回“终端”并恢复有效尺寸；失败 SHALL 留在代码区和原文件标签。成功切换 SHALL 保留所有打开文档与阅读状态，不重建 PTY，也不强制唤起手机软键盘。

#### Scenario: 发送后返回代码继续阅读

- **WHEN** 用户在手机发送某文件位置，回终端补充要求后再进入代码
- **THEN** 返回同一文件标签和阅读位置，其他标签仍在，发送动作没有自动提交或打开键盘

### Requirement: 已知变旧或失效的文档暂停发送

检测到文档来源更新、根身份失效或快照不可用时，系统 SHALL 保留可辨识的旧阅读内容与选区，但禁用该文档的位置发送并提供刷新入口。刷新后内容版本变化 SHALL 清除旧选择；仅视图切换或展开同一版本上下文不得使有效选择失效。

#### Scenario: 阅读中 agent 移动行号

- **WHEN** 用户选择 12–18 行后，自动检测发现该文档内容更新
- **THEN** 原内容和选区继续可读，提示更新并暂停发送；用户刷新后得到新内容，必须重新选择位置

#### Scenario: 同版本展开和完整视图切换

- **WHEN** 用户在同一快照内展开上下文或切换到对应侧的完整文件
- **THEN** 可映射的选择保留相同行号与来源，不因视图切换误标为另一版本

#### Scenario: 外部修改发生于两次检测之间

- **WHEN** 文件在最近一次检查后又被外部程序修改
- **THEN** 引用仍明确来自当前展示版本，页面提供读取/检测时间，不承诺外部并发修改下的实时事务定位
