## Why

手机终端页的顶栏和代码区工具栏挤占了阅读空间。393×851 视口实测：终端顶栏只留给会话标题 10 px，只能看到首字母，“已连接”被挤成竖排。打开一个 Diff 后，屏幕上下共有 7 层控件栏，合计约 312 px，占可见高度 37%。桌面代码面板同样有约 305 px 的控件，根路径重复显示，Diff 的“旧侧/新侧完整文件”在半屏宽度下折成第二行。图片预览（#110）合入后，图片工具栏在手机上也折成两行。用户主要在手机上查看 agent 的输出和产物，需要把常驻控件收敛到真正高频的操作，把空间还给终端和代码内容。

目标平台包括 iOS 27 上的 Safari 标签页和主屏幕 Web App。从 iOS 26 起，添加到主屏幕的网站默认以 Web App（`display-mode: standalone`）打开，没有浏览器地址栏和后退按钮，这是 iPhone 用户的主要使用形态。iOS 27 的 iPhone 仍不支持网页 Fullscreen API（只有 iPad 支持），也不支持 Document Picture-in-Picture；触屏没有悬停提示。精简方案必须在这些限制下保持每个操作可达、可辨识。

## What Changes

- 终端顶栏的连接状态改为只在异常时显示文字（重连中、已退出、不存在）。连接正常时由会话状态点承载，其可访问名称同时包含会话状态与连接状态。桌面和手机都适用。
- 窄屏（小于 640 CSS px）终端顶栏只常驻返回、会话标题、状态点、快捷指令入口（沿用现有显示规则）、草稿、终端/代码切换和终端菜单。全屏、上传文件、滚动到最新位置移入终端菜单，标题获得剩余宽度。宽屏顶栏的按钮布局不变。
- 窄屏终端离开底部（查看历史，或观察者平移离开控制方网格的最新行）时，右下角显示浮动的“回到最新”按钮，点击后滚动到最新输出并隐藏该按钮。
- 代码面板的工作区栏与文件标签栏合并为一行：导航开关、标签条、刷新全部、独立窗口（窄屏不显示）、代码区菜单（仅窄屏）。根路径和导航状态提示移到导航面板顶部。
- 文档栏在宽屏保持一行，沿用 #114 的控件：“查看 Diff / 返回文件”、SVG“预览 / 源码”、图片 Diff 预览来源和“完整文件”菜单。窄屏把这些操作收进代码区菜单，菜单显示完整路径；更新、过期、不可展示原因等提示仍直接显示。Diff 工具栏（增删统计、查找、换行）保持单行，不再调整。
- 引用操作栏：“引用整个文件”只在存在行选择时出现（普通文件与 Diff 一致）。选择方式提示从阅读器移到操作栏左侧，与按钮同一行；窄屏不显示提示，主按钮文字给出当前选择范围。
- 图片工具栏合并为一行（图片信息、缩放比例、适应窗口、1:1）。窄屏触摸设备隐藏放大、缩小按钮，改用已有的双指缩放；宽屏保留。下载按钮保持在动作栏。
- iOS 27 与主屏幕 Web App 兼容：
  - 全屏入口按能力检测：支持 Fullscreen API 时正常提供；iPhone Safari 标签页保留入口，点击后引导用户“添加到主屏幕”；主屏幕 Web App 中不支持时隐藏入口。
  - 带触摸屏设备的主屏幕 Web App 中没有 Document Picture-in-Picture 时隐藏“独立窗口”入口，避免弹出的 App 内浏览器页面遮住终端；没有触摸屏的桌面 Web App（如 macOS Safari）保留。
  - 浮动按钮和新增菜单避开状态栏、主屏幕指示条和软键盘，菜单内容超出时在菜单内滚动。
  - 触屏上的关键控件有可见文字或可访问名称，不依赖悬停提示。窄屏用菜单单选项代替小号 `<select>`（图片预览来源），避免 iOS 聚焦时页面放大。
- 无 **BREAKING** 变更：不改 REST/WebSocket 契约、会话生命周期或引用文本格式。

## Capabilities

### New Capabilities

- `terminal-header`：终端页顶栏的状态呈现、窄屏常驻操作与菜单收纳、全屏入口的平台适配，以及窄屏“回到最新”浮动按钮。

### Modified Capabilities

- `terminal-diff-review`：新增代码区控件按宽度精简的要求（标签行合并、根路径与导航提示位置、窄屏菜单收纳与提示保留、带触摸屏的主屏幕 Web App 下独立窗口入口的显示条件）。原提案中的分段视图控件已由 #114 的“查看 Diff / 返回文件”和“完整文件”菜单取代，不再修改“Diff 行号与完整来源可互通”。
- `terminal-code-references`：新增引用操作栏按选择状态显示的要求（“引用整个文件”的出现条件、提示与操作合并、窄屏范围提示）。
- `code-image-preview`：缩放控件在窄屏触摸设备上由双指缩放替代按钮，包括主屏幕 Web App。该能力当前只存在于未归档的 `add-code-image-preview` 变更中，本变更须在其归档之后归档。

## Impact

- 前端：`web/src/pages/Terminal.svelte`、`web/src/hooks/terminal.svelte.ts`（暴露是否位于底部）、`web/src/capabilities.ts`（全屏与独立窗口能力判断）、`web/src/codePopout.ts`、`CodePanel.svelte`、`CodeNavigator.svelte`、`CodeDocumentView.svelte`、`CodeDiffReader.svelte`、`CodeReader.svelte`、`CodeImageView.svelte`、`web/src/styles.css`。
- 测试：`web/test/e2e/` 中依赖已移入菜单的按钮（“上传文件”“滚动到最新位置”“完整文件”“查看 Diff”、SVG“源码”、预览来源）和“已连接”文字的用例改为新入口；补充 320/393 px 窄屏与 1440 px 宽屏的布局与可达性断言；浏览器组件测试覆盖“回到最新”状态（含观察者）。Chromium 模拟无法覆盖 iOS 行为，需要在 iOS 27 iPhone 的 Safari 标签页和主屏幕 Web App、iPadOS 27（含触控板）上真机检查。
- 文档：`docs/user-stories.md`（US-D03、US-D07、US-D08、新增 US-H08、US-I01、US-I08、US-I09、US-I13、US-I15），`docs/design-system.md` 的紧凑工具栏规则。
- 不涉及：后端、配置、宽屏终端顶栏的按钮布局、代码导航面板内部（搜索框、过滤控件）、新增复制路径等功能。
