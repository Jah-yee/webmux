## ADDED Requirements

### Requirement: 代码区控件按宽度精简

代码面板 SHALL 将导航开关、文件标签条、刷新全部和独立窗口入口放在同一行，标签过多时标签条在该行内横向滚动。代码根路径 SHALL 作为刷新全部按钮提示的一部分，并在导航状态正常时显示在导航面板顶部；导航状态异常（目录或修改列表已更新、检测失败）时，导航面板顶部 SHALL 以该提示和“刷新导航”替代根路径，导航收起时导航开关 SHALL 显示提醒标记并在提示中给出状态。

文档栏在宽屏 SHALL 保持单行：文档路径（过长时保留末尾）、“查看 Diff / 返回文件”、SVG 的“预览 / 源码”、图片 Diff 的预览来源，以及 Diff 的“完整文件”菜单。重命名双方路径可另起一行。

视口宽度小于 640 CSS px 时：

- 独立窗口入口 SHALL 不显示。
- 文档栏的上述操作 SHALL 收进标签行末尾的代码区菜单。菜单 SHALL 显示文档完整路径（重命名时同时显示双方路径），并提供“查看 Diff / 返回文件”、SVG 显示方式单选、图片 Diff 预览来源单选、“修改前的文件 / 修改后的文件”和“刷新文档”。各项与宽屏控件使用同一处理函数和禁用条件。
- 文档的提示信息 SHALL 继续直接显示，不收进菜单：图片变化与大小、内容已更新/文件已不存在/快照已过期/检测失败及其“刷新文档”、不可完整展示的原因、SVG 预览回退说明。
- Diff 工具栏 SHALL 保持单行：增删统计、查找与自动换行。
- 菜单 SHALL 避开状态栏与主屏幕指示条，内容超出可用高度时在菜单内滚动。来源选择使用菜单单选项，不使用会让 iOS 聚焦放大页面的小号 `<select>`。

主屏幕 Web App（`display-mode: standalone`）中，浏览器不支持 Document Picture-in-Picture 且设备带触摸屏时，独立窗口入口 SHALL 不显示（任何宽度），因为弹出的页面会以 App 内浏览器形式覆盖终端。没有触摸屏的桌面 Web App（如 macOS Safari 的 Web App）SHALL 继续按现有规则提供普通弹出窗口。

#### Scenario: 手机 Diff 视图的内容空间

- **WHEN** 在 393×851 视口打开一个文本 Diff
- **THEN** 终端顶栏下方依次为单行标签栏、单行 Diff 工具栏、代码内容和单行操作栏，无横向溢出；代码内容区高度不少于视口高度的 70%

#### Scenario: 手机从菜单打开完整文件

- **WHEN** 手机用户在 Diff 中打开代码区菜单，选择“修改前的文件”
- **THEN** 菜单显示该文件的完整路径；修改前的完整内容在新标签中打开并激活，原 Diff 标签保留

#### Scenario: 手机仍能看到文档提示

- **WHEN** 手机上已打开的文档被外部修改，或打开二进制文件
- **THEN** 文档上方直接显示“内容已更新”和“刷新文档”，或不可展示的原因；无需打开菜单

#### Scenario: 桌面文档栏单行

- **WHEN** 在 1440 px 视口、代码区默认宽度下打开一个 Diff
- **THEN** 标签栏与刷新全部在同一行，文档路径与“完整文件”在同一行，根路径显示在导航面板顶部，不显示代码区菜单

#### Scenario: iOS 主屏幕 Web App 中的代码区菜单

- **WHEN** iOS 27 iPhone 主屏幕 Web App 中打开一个 Diff，再打开代码区菜单
- **THEN** 菜单完整位于状态栏与主屏幕指示条之间，项目过多时可在菜单内滚动；切换预览来源时页面不放大

#### Scenario: iPad 主屏幕 Web App 隐藏独立窗口

- **WHEN** 连接触控板的 iPadOS 27 设备在主屏幕 Web App 中以宽屏打开代码区
- **THEN** 不显示独立窗口入口；同一设备在 Safari 标签页中按现有规则显示

#### Scenario: 桌面 Web App 保留独立窗口

- **WHEN** macOS Safari 用户在没有触摸屏的 Mac 上从 Dock 中的 Web App 打开代码区
- **THEN** 独立窗口入口照常显示，点击后打开普通弹出窗口
