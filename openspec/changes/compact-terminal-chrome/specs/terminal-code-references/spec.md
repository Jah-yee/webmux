## ADDED Requirements

### Requirement: 引用操作栏按选择状态精简

代码区底部操作栏 SHALL 常驻“发送位置到终端/草稿”主操作；存在行选择时，主操作文字 SHALL 包含所选行范围。“引用整个文件”（清除行选择、回到文件级引用）SHALL 仅在存在行选择或无效的跨侧选择时显示，没有行选择时主操作即发送文件级引用；普通文件与 Diff 规则相同。文字 Diff 的当前引用版本（如“修改后 · 工作区”）SHALL 继续显示在操作栏左侧。选择方式提示（如“点击行号选择；Shift 点击选择范围”）SHALL 从阅读器内移到操作栏左侧，与按钮同一行；视口宽度小于 640 CSS px 时 SHALL 不显示该提示。提示文字过长时 SHALL 省略，而不是把按钮挤到下一行。图片文档的下载入口 SHALL 继续位于该操作栏。上述呈现变化 SHALL NOT 改变引用文本、发送目标或发送失败时保留选择的行为。

#### Scenario: 无选择时只发送文件

- **WHEN** 用户打开文件但尚未选择任何行
- **THEN** 操作栏只显示“发送位置到终端”（草稿模式下为“草稿”），不显示“引用整个文件”；点击后插入文件级引用

#### Scenario: 选择后回到文件级引用

- **WHEN** 用户选中第 3–5 行
- **THEN** 主操作文字包含“3-5 行”，并出现“引用整个文件”；点击“引用整个文件”后选区清除、该按钮消失，主操作恢复为文件级引用

#### Scenario: 桌面提示与操作同一行

- **WHEN** 在 1440 px 视口打开 Diff
- **THEN** 操作栏一行内依次显示引用版本、选择方式提示和发送按钮；Diff 内容下方不再有独立提示行

#### Scenario: 手机操作栏单行

- **WHEN** 在 393 px 视口打开文本文件
- **THEN** 不显示选择方式提示，操作栏为单行且所有按钮完整可见
